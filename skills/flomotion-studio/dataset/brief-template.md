# Brief template (output of the interview)

Every field is an object {value, source, status}. source: user | asset | assumption. status: confirmed | assumed | unknown.

Write `brief.md` in the project folder with one `##` section per group below and one line per field:

```
- field: the answer · source: user · status: confirmed · quote: "their words" · note: why
```

`source` is `user`, `asset` or `assumption`; `status` is `confirmed`, `assumed` or `unknown`. An unknown stays visibly unknown; never invent it.

Required groups: product, audience, goal, message, proof, format, taste, voice, constraints, clarity.
