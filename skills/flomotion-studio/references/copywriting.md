# Copywriting rules

Only use facts the person gave you. Every claim needs a source or is removed. Write for the ear and the eye: short, concrete, one idea.

## Hard limits
- Headline beat: <= 6 words (8 hard max). Captions: <= 12 words per scene. Quote: <= 14 words (trim with ellipsis only if the person approves).
- One idea per beat. Verbs over adjectives. No jargon the audience would not say.
- Reading speed: <= 3 words/s for on-screen text.
- Never write superlatives you cannot prove ("best", "fastest", "#1") unless the person supplies the source.

## Hook types (offer 3 options at G1)
| Type | Pattern | Example (invented product "Northwind Notes") |
|---|---|---|
| Curiosity question | "Is X changing how Y?" typed in a field | "Why do meetings still end with no notes?" |
| Bold claim | Short declarative | "Notes write themselves." |
| Number | Concrete figure + unit | "3 hours back every week." (only if sourced) |
| Pain image | Visual, 0-3 words | A pile of tabs; text "Too many tabs…" |
| Relatable moment | Human behavior, funny | Someone typing notes with a phone in their mouth |
| Trend fact | "As X becomes the norm…" | "As meetings move online…" |

## Pain scripts
- Pain flavors (vary them): too many tools / lost context / wasted time / risk / confusion / cost.
- Pattern: "Too many ___…" then a second flavor "___ is lost." then the thesis.
- Keep each pain beat to 3-5 words. The last pain line is calm, not shouting.

## Turn and promise
- Turn line (<= 6 words): "It's time to ___." or "So we built ___." or "Meet ___."
- Promise (<= 8 words): "Simple, secure ___." / "One place for ___." / "___ that just works." State the benefit, not the feature.

## Sentence-splitting (pattern 11)
Write one sentence of 12-20 words, then split it at natural breaths into 3-5 scenes of 2-6 words each. Read it aloud: it must still scan as one sentence. Keep the same baseline or position logic so the eye follows. Example: "As meetings move online, / the way we / take notes / needs to change."

## Template + word swap (pattern 10)
Choose one frame and swap one word: "A new era of ___" with `speed`, `focus`, `clarity`. Keep timing identical; change only the keyword and the background token.

## Emphasis
- Key word in the contrast color (the look's `accent` or white on a block).
- Lead-in lines dimmer than the payoff word.
- Never emphasize more than one word per beat.

## Proof lines
| Type | Pattern |
|---|---|
| Credential | "First to be [certification]." (only if true and sourced) |
| Number | "[number] [unit] [outcome]" + `source` |
| Customer | Quote + name, role, company (permission required) |
| Scale | "Helping thousands of companies" only with a verified count |

## CTA
- One action, imperative: "Try it free." / "Book a demo." / "See it live."
- URL in the look's body font at >= caption min size; hold >= 1 s.
- No more than one URL and one button.

## Voiceover
- Aim 2.0-2.8 words/s. Leave breaths at beat boundaries.
- Voice leads: write the VO, then set on-screen text as keywords from it (not a transcript).
- Match on-screen emphasis to the stressed word of the VO.

## Checklist before showing a script
- [ ] Every headline <= 6 words
- [ ] Every number has a source in the brief
- [ ] Pain, turn, promise, proof, CTA all present (or flagged missing)
- [ ] No invented names, quotes, stats
- [ ] Reads well aloud in the planned duration
